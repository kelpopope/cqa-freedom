## Продукт
«Контроль качества диалогов» для Freedom Broker (брокер, Казахстан). Супервайзер контакт-центра проверяет, как AI оценил работу оператора в чате или звонке по чек-листу из 8 критериев: видит итоговый балл из 100, ответ по каждому критерию (Да / Нет / N/A / шкала), объяснение и реплику-доказательство. Может оспорить оценку (апелляция), проверяющий её рассматривает. Языки диалогов: русский, казахский, английский. Интерфейс на русском.
Это рабочий инструмент: в нём сидят часами. Потом его встроят как компонент в Microsoft Dynamics 365.
Проект — хакатон: жюри оценивает удобство, понятность и «красоту», защита идёт 5 минут на проекторе.

## Проблема, которую решаем
Текущая версия кажется загруженной, глаза устают. Нужно: спокойно, читаемо, с ясной иерархией, но не скучно и не шаблонно. Ощущение — «протокол проверки аудитора»: строгий, доказательный, аккуратный.

## Бренд (обязательно)
Палитра логотипа Freedom Broker:
- светло-зелёный щита #4DB560
- тёмно-зелёный #1D5A3A
- почти чёрный словесного знака #1B1A17
Можно выводить оттенки из этих трёх (тинты нейтралей в сторону зелёного/тёплого), но не добавлять новых «брендовых» цветов. Семантические цвета (ошибка, предупреждение) — приглушённые, только по смыслу.

## Жёсткие ограничения
1. Меняешь только CSS. Все существующие классы, id, data-атрибуты и состояния должны продолжать работать — JS их проставляет (список ниже). Не переименовывай классы. Можно добавлять новые правила к существующим классам и использовать псевдоэлементы.
2. Чистый CSS, без фреймворков, без CDN, без внешних шрифтов (системный стек: "Segoe UI", Inter, system-ui…). Иконки — inline SVG, цвет = currentColor.
3. Всё ограничено корнем `.cqa-root` (компонент живёт внутри чужой страницы). Все цвета, радиусы, отступы — через CSS-переменные `--cqa-*` в tokens.css.
4. Светлая тема — основная; тёмная — через `.cqa-root[data-theme="dark"]`, тоже должна быть аккуратной.
5. Доступность: контраст текста ≥ 4.5:1, видимый фокус (`:focus-visible`), `prefers-reduced-motion`.
6. Адаптив: ≥1280 — две колонки в карточке (транскрипт | оценка); 1100 и меньше — одна колонка; 720 и меньше — мобильная вёрстка без горизонтального скролла.

## Принципы (анти-«AI-слоп»)
- Цвет и выразительность — только в двух «моментах»: (1) итоговый балл с полосой разложения весов `.cqa-weights`; (2) подсветка реплики-доказательства при переходе (`.cqa-msg.is-flash`, `.is-lit`). Остальной хром нейтральный.
- Никаких градиентов (кроме едва заметных тональных), свечений, цветных теней, стекла, неона, эмодзи, пульсаций и бесконечных анимаций, `transition: all`, капса с разрядкой, курсива для акцента.
- Сетка 4 px, одинаковые вещи одинакового размера, числа `tabular-nums` и выровнены вправо.
- Веса шрифта 400/500, 600 — только итоговый балл и заголовки страниц. Минимум 12 px.
- Движение — только как отклик: смена фона/цвета 120–200 мс, одна кривая.
- Тест: если заменить название продукта — экран всё ещё подходит? Тогда это шаблон, усиль характер.
