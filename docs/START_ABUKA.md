# Абука, старт за 15 минут

Ты — участник **A**: сервер + AI-оценка + точность. Интерфейс делает напарник. Весь контекст проекта уже записан в `CLAUDE.md` — твой Claude прочитает его сам.

## 1. GitHub (5 мин)
1. github.com → **New repository** → имя, например `cqa-freedom` → **Public** → ничего не добавлять (без README, без .gitignore) → Create.
2. Settings → Collaborators → **Add people** → добавить напарника.
3. Скинуть напарнику ссылку на репозиторий. Он запушит первый коммит с документами.

## 2. OpenAI (3 мин)
1. platform.openai.com → создать **Project** `cqa-hackathon`.
2. В проекте: Limits → бюджет **$100**, уведомления.
3. API keys → создать ключ для проекта. **Никому не отправлять, нигде не коммитить.**

## 3. Локально (5 мин, после пуша напарника)
```bash
git clone <ссылка на репозиторий>
cd <папка репозитория>
copy .env.example .env
```
В `.env` вставить:
- `OPENAI_API_KEY=` — твой ключ;
- `ORG_API_URL=` — адрес API организаторов **без** `&group_id=DEV` на конце (кнопка «Открыть GET для DEV» на стр. 3 гайда; или возьми у напарника в личке).

```bash
git checkout -b backend/base
```

## 4. Claude Code
Открыть Claude Code в папке репозитория и вставить:

```
Я Абука, участник A (бэкенд + LLM + точность). Прочитай CLAUDE.md, docs/PLAN.md, docs/API_CONTRACT.md, docs/RESEARCH.md и docs/BUDGET.md.
Задача на первые часы — задачи A1–A6 из PLAN.md: к ~20:00 должен работать путь
«импорт DEV из API организаторов → оценка одного диалога через gpt-6.1-sol → JSON по API_CONTRACT».
Начни с A1 (каркас FastAPI + SQLite + раздача frontend/ + /api/health) и A4 (scoring.py с тестами — это критично для точности).
Работай в ветке backend/base, коммить часто. Не трогай frontend/. Ключ и ORG_API_URL — только из .env.
Сначала коротко покажи план, потом делай.
```

## 5. Что важно помнить
- **Точность — главный критерий отбора.** После A1–A6 сразу A11 (свой эталон на DEV) и A12 (подстройка промпта).
- Баллы считает код (`scoring.py`), модель только отвечает по критериям и даёт номера реплик.
- Контракт с интерфейсом — `docs/API_CONTRACT.md`. Хочешь поменять — сначала скажи напарнику.
- Мержи в `main`: ~20:00, ~01:00, ~08:00. Фича-фриз 10:00. Финальный коммит 11:45.
- Ссылку на репозиторий отправить организаторам заранее.
