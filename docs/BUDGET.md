# Модель и бюджет (коротко)

## Выбор: OpenAI `gpt-6.1-sol`
- ≈ $0,07 за оценку одного диалога, весь DEV (65) ≈ $4,5.

## Что нужно от модели
1. Понимать русский, казахский и английский.
2. Точно следовать правилам чек-листа (особенно «Нет» vs N/A).
3. Отвечать строго в JSON (Structured Outputs).
4. Ссылаться на номер реальной реплики, не выдумывать цитаты.
5. Давать одинаковый ответ на один и тот же диалог.

Не нужно: длинный контекст (диалог — до ~5 тыс. токенов), картинки, звук, инструменты.

Казахский: публичных замеров нет → проверяем на наших 15 KZ-диалогах.

## Сколько потратим
Реально **$30–80** из $2 500. Ставим лимит проекта в OpenAI на $100.

## Ключ
Только в `.env` на бэкенде. Не в git, не во фронте — репозиторий публичный.
