## 0. Принятые решения (по умолчанию — поменять до старта, если не согласны)

| Что | Решение | Почему |
|---|---|---|
| Бэкенд | Python 3.11+ · FastAPI · SQLite (stdlib `sqlite3`) | быстро, удобно для LLM, один процесс отдаёт и API, и фронт → нет CORS |
| Фронт | чистые HTML + CSS + JS (ES-модули), без сборщика и фреймворков | требование задания + D365-компонент |
| LLM | **OpenAI gpt-6.1-sol** (см. BUDGET.md) | точность, есть кредиты |
| Расчёт баллов | только код (`scoring.py`), LLM баллы не считает | детерминированность, точность |
| ID реплики | индекс в массиве `transcript` (0..N-1) | стабильно; якорь во фронте `#msg-{index}` |
| Git | один публичный репозиторий, ветки `backend/*` и `frontend/*`, мерж в `main` | без конфликтов: каждый трогает только свою папку |
