# Дизайн интерфейса CQA

Правила собраны из двух открытых скиллов и применяются к каждому экрану:
- **unslop** — Damir Sokolovsky (@heydamir), https://github.com/heydamir/unslop, CC BY 4.0.
- **frontend-design** — Anthropic, https://github.com/anthropics/skills/tree/main/skills/frontend-design.

## Направление (5 строк)
- **Продукт:** рабочий инструмент супервайзера контакт-центра Freedom Broker — проверить, как AI оценил диалог оператора, найти риски, разобрать апелляцию.
- **Характер:** строгий, доказательный, спокойный.
- **Мир:** протокол проверки аудитора: лист с пометками на полях, ссылки на конкретные строки, подпись проверяющего.
- **Моменты (где цвет и выразительность):** 1) итоговый балл с прозрачным разложением весов; 2) реплика-доказательство, подсвеченная при переходе.
- **Подпись (signature):** «пометка на полях» — номер критерия на левом поле реплики, на которую он ссылается. Используется только для связи «критерий ↔ реплика».

## Токены
- **Палитра логотипа Freedom Broker:** светло-зелёный щита `#4DB560` (индикаторы, заливка баллов), тёмно-зелёный `#1D5A3A` (кнопки, активная навигация, ссылки; контраст ~8:1), почти чёрный словесного знака `#1B1A17` (основной текст).
- Нейтральная шкала: мягкий фон `#f4f5f2` (не слепит), поверхность `#ffffff`, линии — текст с прозрачностью 8 %, вторичный текст `#4f544f`, третичный `#7b807a`.
- Семантика приглушённая и только по смыслу: «Нет» и грубая ошибка — `#b93a2f`, частично — янтарный, N/A — серый кружок.
- Ответы показываются точкой и текстом, без залитых «таблеток».
- Шрифт: системный (Segoe UI / Inter), база 14 px, реплики 15 px, цифры `tabular-nums`. Веса 400 и 500, 600 — только итог и заголовки.
- Сетка 4 px. Контролы 36 px, радиусы: контролы 8, карточки 12.
- Разгрузка: на полях реплик только номера нарушенных критериев; критерии свёрнуты; служебная информация — одной строкой.
- Иконки: один набор (контурные, 16 px, линия 1.5), цвет = цвет текста.

## Правила (чек-лист перед каждым коммитом)
- [ ] Цвет — только в двух «моментах» и в семантике; хром (фон, кнопки, рамки) нейтральный.
- [ ] Никаких градиентов, свечений, цветных теней, эмодзи, капса с разрядкой, курсива для акцента.
- [ ] Нет «A · B · C» мета-строк и стрелок «→» в тексте кнопок.
- [ ] Отступы кратны 4, одинаковые вещи одинакового размера, числа выровнены вправо.
- [ ] Короткие подписи без точки на конце, без восклицательных знаков, без «AI-powered».
- [ ] Движение только как отклик: смена цвета/фона, лёгкий сдвиг меню; никаких пульсаций и бесконечных анимаций; `transition` только по именованным свойствам.
- [ ] Видимый фокус, работа с клавиатуры, `prefers-reduced-motion`.
- [ ] Тест шаблонности: если подменить название продукта — экран всё ещё подходит? Если да — усилить направление.
